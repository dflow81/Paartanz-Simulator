# Technikkatalog

Diese Datei wird mit `node tests/doku.js` aus den Figurendaten erzeugt. Bitte nicht von Hand bearbeiten.

Jede Figur hat für **jeden Schritt von Herr und Dame**: Belastungsfuß, freier Fuß, Fußtechnik (Ferse, Spitze, Ballen, ganzer Fuß), Heben (Rise), Senken (Fall), CBM, CBMP, Ausrichtung (Alignment) und Sway.

**Herkunft der Angaben:** Bei Figuren mit Quelle (mit † markiert) stammen Fußarbeit und Sway aus dem angegebenen Figurendiagramm. Alle anderen Angaben werden nach festen Regeln aus den Schritten abgeleitet (`js/technik.js`). Sie sind eine Lernhilfe, keine Abschrift aus einem Technikbuch.

**Ausrichtung:** Sie hängt davon ab, wo die Figur beginnt. Im Katalog beginnt der Herr an einer langen Seite mit Blick in Tanzrichtung. In der App steht die tatsächliche Ausrichtung beim Tanzen.

## Begriffe

| Begriff | Bedeutung |
|---|---|
| H, T, B, F | Ferse (Heel), Spitze (Toe), Ballen (Ball), ganzer Fuß (Flat) |
| HT, TH, BF | Abrollen in dieser Reihenfolge, z. B. HT = erst Ferse, dann Spitze |
| Heben / Senken | Rise and Fall, aus der Zählzeit abgeleitet |
| CBM | Contra Body Movement: Körper dreht zum bewegten Fuß hin, zu Beginn einer Drehung |
| CBMP | Contra Body Movement Position: Fuß wird auf die Körperlinie des anderen Fußes gesetzt |
| Sway | Neigung des Körpers: gerade, links, rechts, – keine |
| LOD | Line of Dance, Tanzrichtung gegen den Uhrzeigersinn |
| DW, DC, W, C | diagonal zur Wand, diagonal zur Mitte, Wand, Mitte |
