# Technikkatalog

Diese Datei wird mit `node tests/doku.js` aus den Figurendaten erzeugt. Bitte nicht von Hand bearbeiten.

**Wichtig:** Die Technikangaben werden nach festen Regeln aus den Schritten abgeleitet (`js/technik.js`). Sie sind eine Lernhilfe, keine Abschrift aus einem Technikbuch. Ausnahme: Bei Figuren mit Quelle (mit † markiert) stammen Fußarbeit und Sway aus dem angegebenen Figurendiagramm.

## Begriffe

| Begriff | Bedeutung |
|---|---|
| H, T, B, F | Ferse (Heel), Spitze (Toe), Ballen (Ball), ganzer Fuß (Flat) |
| HT, TH, BF | Abrollen in dieser Reihenfolge, z. B. HT = erst Ferse, dann Spitze |
| Heben und Senken | Rise and Fall: aus der Zählzeit abgeleitet |
| CBM | Contra Body Movement: Körper dreht zum bewegten Fuß hin, zu Beginn einer Drehung |
| CBMP | Contra Body Movement Position: Fuß wird auf die Körperlinie des anderen Fußes gesetzt |
| Sway | Neigung des Körpers: g gerade, l links, r rechts, – keine |
| LOD | Line of Dance, Tanzrichtung gegen den Uhrzeigersinn |
| DW, DC, W, C | diagonal zur Wand, diagonal zur Mitte, Wand, Mitte |

Belastungsfuß, freier Fuß und Ausrichtung im Raum stehen je Schritt in der App unter „Schritte erklärt“ → „Technikdaten einblenden“.
