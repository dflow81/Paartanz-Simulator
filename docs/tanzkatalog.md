## Beispiele des Folgen-Generators

Je Medaillenstufe automatisch erzeugt, mit gültigen Übergängen. In der App erzeugt jeder Klick eine neue Folge.

### Slowfox

- **Bronze:** Dreierschritt → Rechtsdrehung → Rückwärts-Dreierschritt → Links vorbei mit Linksdrehung, dann zurück → Rechtsdrehung mit Fersendrehung → Feather Finish
- **Silber:** Open Telemark → Weave aus der Promenade → Dreierschritt → Hover Feather → Ein Schritt rück, dann Federschritt → Links vorbei mit Linksdrehung, dann zurück → Rechtsdrehung → Hover Cross
- **Gold:** Hover Cross → Hover-Telemark → Open Telemark → Weave aus der Promenade → Bounce Fallaway mit Weave-Ende → Top Spin → Open Impetus → Natural Zig-Zag aus der Promenade → Rückwärts-Federschritt → Natural Weave → Dreierschritt
- **Goldstar:** Hover-Telemark → Tumble Turn → Open Telemark → Natural Zig-Zag aus der Promenade → Rückwärts-Federschritt → Natural Telemark → Linksdrehung → Bounce Fallaway mit Weave-Ende → Open Impetus → Weave aus der Promenade → Top Spin → Wellenschritt

### Quickstep

- **Bronze:** Running Finish → Kreuzschritt rückwärts → Fortschreitendes Chassé → Linksdrehung mit Chassé → Progressives Chassé → Rechtskreisel
- **Silber:** Cross Swivel → Kreuzschritt rückwärts → Fortschreitendes Chassé → V6 → Linksdrehung mit Chassé → Tipple-Chassé rechts → Reverse Pivot → Quick Open Reverse
- **Gold:** Rumba Cross → Fishtail → Hover Corté → Tipsy nach rechts → Cross Swivel → Quick Open Reverse → Fortschreitendes Chassé → V6 → Kreuzschritt rückwärts → Linksdrehung mit Chassé
- **Goldstar:** Rumba Cross → Fishtail → Hover Corté → V6 → Tipsy nach rechts → Cross Swivel → Quick Open Reverse → Hüpfer vorwärts → Kreuzschritt rückwärts → Pfeffermühle → Fortschreitendes Chassé → Quick Open Reverse → Linksdrehung mit Chassé

### Tango

- **Bronze:** Progressive Link → Rechtsdrehung aus der Promenade → Offene Linksdrehung → Linksdrehung → Wiegeschritt → Rück-Corté
- **Silber:** Reverse Outside Swivel → Viererschritt → Rechtsdrehung aus der Promenade → Linksdrehung → Rückwärts offene Promenade → Promenade Link → Rück-Corté → Progressive Link → Natural Promenade Turn → Offene Promenade
- **Gold:** Brush Tap → Viererschritt → Offene Promenade → Reverse Outside Swivel → Fünferschritt → Promenade Link → Fallaway Four Step → Promenade → Außenseitiger Wechsel → Contra Check → Natural Twist Turn → Rechts-Wiegedrehung
- **Goldstar:** Rechts-Wiegedrehung → Outside Swivel → Natural Promenade Turn → Fallaway-Promenade → Contra Check → Natural Twist Turn → Rock zurück → Fünferschritt → The Chase → Promenade Link → Außenseitiger Wechsel → Reverse Outside Swivel → Brush Tap → Progressiver Seitschritt

### Langsamer Walzer

- **Bronze:** Double Reverse Spin → Außenseitlicher Wechsel → Rückwärts-Wechsel mit rechts → Pendelschritt → Rückwärts-Wechsel mit links → Vorwärts-Wechsel mit rechts
- **Silber:** Zögerschritt → Open Impetus → Cross Hesitation → Kreuzschritt vorwärts → Reverse Corté → Rechtskreisel mit Chassé → Turning Lock → Rechtsdrehung mit Impetus → Zögerwechsel
- **Gold:** Kreuzschritt vorwärts → Flechtschritt → Left Whisk → Telemark → Open Impetus → Weave aus der Promenade → Turning Lock nach rechts → Wing → Kreuzschritt rückwärts → Open Telemark → Cross Hesitation
- **Goldstar:** Hover Corté → Open Telemark → Weave aus der Promenade → Rechtsdrehung mit Impetus → Closed Wing → Open Impetus → Cross Hesitation → Flechtschritt → Zögerwechsel → Schwebeschritt → Contra Check → Wing → Telemark → Kreuzschritt rückwärts → Außenseitlicher Wechsel

### Cha-Cha-Cha

- **Bronze:** Rückwärts-Lock → Damendrehung rechts unter dem Arm → Fächer → Hockeystick → New Yorker → Closed Hip Twist → Alemana
- **Silber:** Drei Cha-Cha-Chas → Closed Hip Twist → Hockeystick → Curl → Alemana → Schulter an Schulter → Vorwärts-Chassé → Rückwärts-Lock
- **Gold:** Drei Cha-Cha-Chas → Spiral → Aida → Offene Basic → Kubanische Brüche → Hand to Hand → Grundschritt in offener Haltung → Opening Out → Rechtskreisel → Seitliches Chassé
- **Goldstar:** Drei Cha-Cha-Chas → Spiral → New Yorker → Grundschritt in offener Haltung → Kubanische Brüche → Offene Basic → Curl → Hockeystick → Fencing → Reverse Top → Rechtskreisel → Cross Basic

### Rumba

- **Bronze:** Schulter an Schulter → Damendrehung rechts unter dem Arm → Fächer → Hockeystick → New Yorker → Closed Hip Twist → Alemana
- **Silber:** Reverse Top → Spiral → Curl → Alemana → Schulter an Schulter → Seitschritte → Fächer → Hockeystick → Aida → Hand to Hand → Opening Out
- **Gold:** Rechtskreisel → Reverse Top → Spiral → Curl → Hockeystick → Fencing → Offener Hip Twist → Alemana → Damendrehung rechts unter dem Arm → Seit-Wiegeschritt
- **Goldstar:** Rechtskreisel → Damendrehung rechts unter dem Arm → Seitschritte → Spiral → Offener Hip Twist → Alemana → Reverse Top → Grundschritt → Fächer → Hockeystick → Curl → Alemana

### Salsa

- **Bronze:** Damendrehung links → Dile que no → Platzwechsel mit Damendrehung → Platzwechsel → Suzie Q → Damendrehung rechts
- **Silber:** Platzwechsel mit Damendrehung → Vacílala → Sombrero → Cumbia-Schritt → Copa → Damendrehung links → Dile que no → Damendrehung rechts
- **Gold:** Damendrehung links → Suzie Q → Platzwechsel → Copa → Sombrero → Cumbia-Schritt → Grundschritt in offener Haltung → Vacílala → Herrendrehung rechts → Rückwärts-Grundschritt
- **Goldstar:** Sombrero → Grundschritt in offener Haltung → Cumbia-Schritt → Herrendrehung rechts → Copa → Vacílala → Grundschritt rückwärts → Platzwechsel → Grundschritt → Dile que no → Damendrehung rechts → Damendrehung links

### Discofox

- **Bronze:** Grundschritt mit Rechtsdrehung → Platzwechsel → Rückführung in die geschlossene Haltung → Grundschritt am Platz → Promenade → Grundschritt
- **Silber:** Seitschritte links und rechts → Schal → Hammerlock → Handwechsel hinter dem Rücken → Doppelte Damendrehung rechts → Rückführung in die geschlossene Haltung → Schulterfasser → Promenade
- **Gold:** Grundschritt → Doppelte Damendrehung rechts → Schal → He Goes – She Goes → Brezel → Rückführung in die geschlossene Haltung → Grundschritt am Platz → Schulterfasser → Hammerlock → Herrensolo → Grundschritt in offener Haltung → Offene Haltung rückwärts → Grundschritt mit Kick
- **Goldstar:** Grundschritt mit Rechtsdrehung → Handwechsel hinter dem Rücken → Schal → He Goes – She Goes → Rückführung in die geschlossene Haltung → Grundschritt mit Kick → Brezel → Tunnel → Grundschritt in offener Haltung → Schulterfasser → Doppelte Damendrehung rechts → Damendrehung links → Hammerlock → Wickler → Seitschritt nach rechts
