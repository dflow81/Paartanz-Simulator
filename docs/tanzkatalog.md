## Beispiele des Folgen-Generators

Je Medaillenstufe automatisch erzeugt, mit gültigen Übergängen. In der App erzeugt jeder Klick eine neue Folge.

### Slowfox

- **Bronze:** Dreierschritt → Rechtsdrehung → Rückwärts-Dreierschritt → Links vorbei mit Linksdrehung, dann zurück → Rechtsdrehung mit Fersendrehung → Feather Finish
- **Silber:** Open Telemark → Weave aus der Promenade → Dreierschritt → Hover Feather → Ein Schritt rück, dann Federschritt → Links vorbei mit Linksdrehung, dann zurück → Rechtsdrehung → Hover Cross
- **Gold:** Natural Twist Turn → Weave aus der Promenade → Fallaway Reverse and Slip Pivot → Bounce Fallaway mit Weave-Ende → Wellenschritt → Hover-Telemark → Rückwärts-Federschritt → Natural Weave → Open Telemark → Natural Zig-Zag aus der Promenade → Dreierschritt
- **Goldstar:** Curved Feather → Rückwärts-Federschritt → Natural Twist Turn → Natural Zig-Zag aus der Promenade → Tumble Turn → Open Telemark → Weave aus der Promenade → Fallaway Reverse and Slip Pivot → Top Spin → Hover-Telemark → Extended Reverse Wave → Hover Feather → Wellenschritt → Bounce Fallaway mit Weave-Ende → Dreierschritt

### Quickstep

- **Bronze:** Rechtsdrehung → Running Finish → Linksdrehung mit Chassé → Reverse Pivot → Fortschreitendes Chassé → Kreuzschritt rückwärts → Fortschreitendes Chassé → Kreuzschritt rückwärts → Linksdrehung mit Chassé
- **Silber:** Kreuzschritt vorwärts → Rechtsdrehung → Progressives Chassé → Six Quick Run → Running Finish → Fortschreitendes Chassé → Cross Swivel → V6 → Quick Open Reverse → Linksdrehung mit Chassé
- **Gold:** Fallaway Natural Turn → Six Quick Run → Tipsy nach links → Running Right Turn → Tipple-Chassé rechts → Fishtail → Rumba Cross → Rechtskreisel → Hover Corté → Cross Swivel → Quick Open Reverse → Tipsy nach rechts → Linksdrehung mit Chassé
- **Goldstar:** Pfeffermühle → Hüpfer vorwärts → Tipsy nach rechts → Cross Swivel → Quick Open Reverse → V6 → Linksdrehung mit Chassé → Fallaway Natural Turn → Hover Corté → Fortschreitendes Chassé → Hüpfer vorwärts → Kreuzschritt rückwärts

### Tango

- **Bronze:** Linksdrehung → Rück-Corté → Progressive Link → Promenade → Rock zurück → Rock zurück
- **Silber:** Rechts-Wiegedrehung → Rückwärts offene Promenade → Offene Promenade → Viererschritt → Natural Promenade Turn → Promenade Link → Außenseitiger Wechsel → Rock zurück
- **Gold:** Außenseitiger Wechsel → Outside Swivel → Promenade Link → Fallaway Four Step → Offene Promenade → Contra Check → Natural Twist Turn → Rechts-Wiegedrehung → Fünferschritt → The Chase → Fallaway-Promenade
- **Goldstar:** Rechts-Wiegedrehung → Fallaway Four Step → Fallaway-Promenade → Viererschritt → Natural Promenade Turn → The Chase → Offene Promenade → Rückwärts offene Promenade → Promenade Link → Outside Swivel → Spanish Drag → Natural Twist Turn

### Langsamer Walzer

- **Bronze:** Linksdrehung → Back Whisk → Chassé aus der Promenade → Reverse Corté → Rechtsdrehung → Rückwärts-Wechsel mit rechts
- **Silber:** Rechtsdrehung mit Impetus → Reverse Corté → Rechtsdrehung → Rechtskreisel mit Chassé → Zögerwechsel → Zögerschritt → Seitliche Balance → Back Whisk → Cross Hesitation
- **Gold:** Closed Wing → Open Telemark → Cross Hesitation → Rechtsdrehung mit Impetus → Rechtskreisel → Rechtskreisel mit Chassé → Turning Lock → Zögerwechsel → Schwebeschritt → Fallaway Reverse and Slip Pivot → Open Impetus → Weave aus der Promenade
- **Goldstar:** Closed Wing → Drag Hesitation → Hinge Line → Curved Feather → Schwebeschritt → Open Impetus → Wing → Außenseitlicher Wechsel → Zögerwechsel → Kreuzschritt rückwärts → Telemark → Vorwärts-Wechsel mit links

### Cha-Cha-Cha

- **Bronze:** Schulter an Schulter → Seitliches Chassé → Vorwärts-Chassé → Rückwärts-Lock → Time Step → Closed Hip Twist → Alemana
- **Silber:** Reverse Top → Closed Hip Twist → Alemana → Drei Cha-Cha-Chas → Rückwärts-Lock → Vorwärts-Chassé → Spiral → Offener Hip Twist → Hockeystick → Curl → Alemana
- **Gold:** Drei Cha-Cha-Chas → Rechtskreisel → Spiral → Advanced Hip Twist → Hockeystick → Aida → Kubanische Brüche → Sliding Doors → Fencing → Offener Hip Twist → Alemana
- **Goldstar:** Reverse Top → Rechtskreisel → Grundschritt am Platz → Fächer → Hockeystick → Rope Spinning → Aida → Spiral → Sliding Doors → Curl → Alemana → Drei Cha-Cha-Chas

### Rumba

- **Bronze:** Fächer → Hockeystick → New Yorker → Platzdrehung → Schulter an Schulter → Seitschritte
- **Silber:** Fächer → Hockeystick → Aida → Platzdrehung → Spiral → Offener Hip Twist → Alemana → Schulter an Schulter
- **Gold:** Reverse Top → Spiral → Advanced Hip Twist → Three Alemanas → Cross Basic → Opening Out from Reverse Top → Rechtskreisel → Schulter an Schulter → Grundschritt am Platz → Offener Hip Twist → Hockeystick → Sliding Doors → Opening Out
- **Goldstar:** Rechtskreisel → Opening Out from Reverse Top → Reverse Top → Grundschritt am Platz → Closed Hip Twist → Alemana → Seit-Wiegeschritt → Spiral → Offener Hip Twist → Hockeystick → Continuous Hip Twist → Advanced Hip Twist → Three Alemanas

### Salsa

- **Bronze:** Damendrehung rechts → Platzwechsel mit Damendrehung → Platzwechsel → Dile que no → Grundschritt am Platz → Cumbia-Schritt → Grundschritt in offener Haltung → Cumbia-Schritt → Damendrehung links
- **Silber:** Damendrehung rechts → Damendrehung links → Copa → Cumbia-Schritt → Grundschritt in offener Haltung → Exhíbela → Sácala → Sombrero → Setenta → Dile que no → Grundschritt rückwärts
- **Gold:** Montaña → Exhíbela → Adiós → Sombrero → Copa → Setenta → Kentucky → Sácala → Vacílala → Herrendrehung rechts
- **Goldstar:** Copa → Grundschritt in offener Haltung → Herrendrehung rechts → Montaña → Vacílala → Adiós → Tumba Francesa → Cumbia-Schritt → Setenta → Grundschritt in Kreuzhandfassung → Sombrero → Exhíbela → Damendrehung links

### Discofox

- **Bronze:** Herrensolo → Offene Haltung rückwärts → Grundschritt in offener Haltung → Rückführung in die geschlossene Haltung → Grundschritt am Platz → Damensolo links → Damendrehung links → Wickler → Grundschritt mit Linksdrehung
- **Silber:** Grundschritt am Platz → Schattenposition → Tunnel → Herrensolo → Promenade → Seitschritt nach rechts → Schulterfasser → Schal → He Goes – She Goes → Rückführung in die geschlossene Haltung
- **Gold:** Seitschritt nach rechts → Hammerlock → Schal → Sliding Doors → Rückführung in die geschlossene Haltung → Grundschritt am Platz → Tunnel → Offene Haltung rückwärts → Grundschritt in offener Haltung → He Goes – She Goes → Schulterfasser → Brezel → Seitschritte links und rechts
- **Goldstar:** Grundschritt mit Kick → Handwechsel hinter dem Rücken → Schal → Rückführung in die geschlossene Haltung → Grundschritt am Platz → Brezel → Sliding Doors → Tunnel → Grundschritt in offener Haltung → Hammerlock → Seilwurf → Schulterfasser → He Goes – She Goes → Lasso → Grundschritt mit Rechtsdrehung
