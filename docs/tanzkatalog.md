## Beispiele des Folgen-Generators

Je Medaillenstufe automatisch erzeugt, mit gültigen Übergängen. In der App erzeugt jeder Klick eine neue Folge.

### Slowfox

- **Bronze:** Federschritt → Links vorbei mit Linksdrehung, dann zurück → Rechtsdrehung mit Fersendrehung → Rückwärts-Dreierschritt → Dreierschritt → Rechtsdrehung
- **Silber:** Natural Weave → Dreierschritt → Rückwärts-Dreierschritt → Ein Schritt rück, dann Federschritt → Top Spin → Richtungswechsel → Feather Finish → Open Telemark → Weave aus der Promenade
- **Gold:** Hover-Telemark → Open Telemark → Weave aus der Promenade → Rückwärts-Federschritt → Natural Twist Turn → Weave aus der Promenade → Top Spin → Bounce Fallaway mit Weave-Ende → Open Impetus → Weave aus der Promenade
- **Goldstar:** Hover-Telemark → Top Spin → Tumble Turn → Open Telemark → Weave aus der Promenade → Rückwärts-Federschritt → Rechts, seit, ran mit Rechtsdrehung → Open Impetus → Weave aus der Promenade → Ein Schritt rück, dann Federschritt → Wellenschritt → Bounce Fallaway mit Weave-Ende

### Quickstep

- **Bronze:** Tipple-Chassé rechts → Progressives Chassé → Kreuzschritt vorwärts → Rechtskreisel → Rechtsdrehung → Vierteldrehung und Chassé
- **Silber:** Rechtsdrehung → Tipple-Chassé rechts → Fishtail → Running Right Turn → Six Quick Run → Running Finish → Cross Swivel → Linksdrehung mit Chassé
- **Gold:** Cross Swivel → Quick Open Reverse → V6 → Fortschreitendes Chassé → Kreuzschritt rückwärts → Linksdrehung mit Chassé → Rechtsdrehung mit Zögern → V6 → Cross Swivel → Kreuzschritt rückwärts
- **Goldstar:** Cross Swivel → V6 → Pfeffermühle → Hüpfer vorwärts → Kreuzschritt rückwärts → Fortschreitendes Chassé → Quick Open Reverse → V6 → Linksdrehung mit Chassé → Six Quick Run → Running Right Turn → Hover Corté

### Tango

- **Bronze:** Progressive Link → Promenade → Linksdrehung → Rück-Corté → Wiegeschritt → Offene Linksdrehung
- **Silber:** Rückwärts offene Promenade → Natural Promenade Turn → Offene Promenade → Outside Swivel → Rechtsdrehung aus der Promenade → Offene Linksdrehung → Außenseitiger Wechsel → Progressive Link → Promenade
- **Gold:** Rechts-Wiegedrehung → Contra Check → Natural Twist Turn → Rechts-Wiegedrehung → Rückwärts offene Promenade → Fallaway-Promenade → Outside Swivel → Natural Promenade Turn → Rechtsdrehung aus der Promenade → Außenseitiger Wechsel
- **Goldstar:** Outside Swivel → Offene Promenade → Fünferschritt → Natural Promenade Turn → Fallaway-Promenade → Außenseitiger Wechsel → Rückwärts offene Promenade → Rechtsdrehung aus der Promenade → Fallaway Four Step → Promenade → Viererschritt → Offene Promenade

### Langsamer Walzer

- **Bronze:** Zögerschritt → Linksdrehung → Wischer → Chassé aus der Promenade → Rechtsdrehung → Rückwärts-Wechsel mit rechts
- **Silber:** Open Telemark → Weave aus der Promenade → Kreuzschritt vorwärts → Rechtskreisel → Rechtsdrehung mit Impetus → Zögerwechsel → Double Reverse Spin → Seitliche Balance
- **Gold:** Drag Hesitation → Contra Check → Wing → Open Telemark → Cross Hesitation → Turning Lock → Kreuzschritt vorwärts → Hover Corté → Kreuzschritt rückwärts → Outside Spin
- **Goldstar:** Open Telemark → Weave aus der Promenade → Kreuzschritt vorwärts → Zögerwechsel → Contra Check → Cross Hesitation → Rechtskreisel mit Chassé → Turning Lock → Rechtsdrehung mit Impetus → Hover Corté → Drag Hesitation → Schwebeschritt

### Cha-Cha-Cha

- **Bronze:** Schulter an Schulter → Seitliches Chassé → Vorwärts-Chassé → Rückwärts-Lock → Damendrehung rechts unter dem Arm → Grundschritt am Platz
- **Silber:** Spiral → Aida → Kubanische Brüche → Offene Basic → Vorwärts-Chassé → Seitliches Chassé → Drei Cha-Cha-Chas → Time Step
- **Gold:** Spiral → Offener Hip Twist → Hockeystick → Aida → Fächer → Alemana → Vorwärts-Chassé → Drei Cha-Cha-Chas → Schulter an Schulter → Rechtskreisel
- **Goldstar:** Drei Cha-Cha-Chas → Spiral → Offener Hip Twist → Alemana → Fächer → Hockeystick → Aida → Kubanische Brüche → Fencing → Opening Out → Schulter an Schulter → Rechtskreisel

### Rumba

- **Bronze:** Schulter an Schulter → Damendrehung rechts unter dem Arm → Platzdrehung → Offene Basic → Hand to Hand → Grundschritt am Platz
- **Silber:** Fächer → Hockeystick → Aida → Offene Basic → Platzdrehung → Spiral → New Yorker → Opening Out
- **Gold:** Spiral → Fencing → New Yorker → Offener Hip Twist → Alemana → Fächer → Hockeystick → Rechtskreisel → Vorwärts-Gehschritte → Aida → Offene Basic → Opening Out
- **Goldstar:** Fächer → Hockeystick → Offener Hip Twist → Alemana → Spiral → Aida → Offene Basic → Rechtskreisel → Grundschritt → Damendrehung rechts unter dem Arm → Seitschritte → Schulter an Schulter

### Salsa

- **Bronze:** Damendrehung links → Platzwechsel → Platzwechsel mit Damendrehung → Dile que no → Damendrehung rechts → Grundschritt
- **Silber:** Damendrehung rechts → Platzwechsel → Dile que no → Sombrero → Cumbia-Schritt → Platzwechsel mit Damendrehung → Damendrehung links → Copa → Grundschritt in offener Haltung → Vacílala → Grundschritt rückwärts
- **Gold:** Copa → Cumbia-Schritt → Grundschritt in offener Haltung → Herrendrehung rechts → Suzie Q → Platzwechsel mit Damendrehung → Sombrero → Vacílala → Grundschritt in Kreuzhandfassung → Damendrehung rechts
- **Goldstar:** Grundschritt am Platz → Copa → Cumbia-Schritt → Grundschritt in offener Haltung → Herrendrehung rechts → Damendrehung rechts → Damendrehung links → Platzwechsel mit Damendrehung → Sombrero → Rückwärts-Grundschritt → Dile que no → Grundschritt rückwärts

### Discofox

- **Bronze:** Grundschritt mit Kick → Wickler → Offene Haltung rückwärts → Herrensolo → Herrensolo → Grundschritt in offener Haltung → Damensolo links → Damensolo rechts → Rückführung in die geschlossene Haltung
- **Silber:** Grundschritt → Tunnel → Wickler → Promenade → Grundschritt am Platz → Doppelte Damendrehung rechts → Rückführung in die geschlossene Haltung → He Goes – She Goes → Herrensolo → Schattenposition → Seitschritte links und rechts
- **Gold:** Grundschritt am Platz → Schal → Tunnel → Grundschritt in offener Haltung → He Goes – She Goes → Hammerlock → Rückführung in die geschlossene Haltung → Grundschritt mit Linksdrehung → Doppelte Damendrehung rechts → Grundschritt in Kreuzhandfassung → Brezel → Handwechsel hinter dem Rücken → Grundschritt mit Kick
- **Goldstar:** Grundschritt → Doppelte Damendrehung rechts → Schal → Handwechsel hinter dem Rücken → Rückführung in die geschlossene Haltung → Grundschritt rückwärts → Hammerlock → Tunnel → Offene Haltung rückwärts → He Goes – She Goes → Brezel → Grundschritt am Platz
